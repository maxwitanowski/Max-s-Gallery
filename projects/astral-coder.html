Astral Coder

One window for every coding agent. Claude Code, Codex, Gemini CLI, Grok, Copilot, Aider and local models each run untouched inside a real terminal, sorted into projects, workspaces and sessions. Claude Code also gets a proper chat: streamed replies, thinking, expandable tool calls, permission prompts, and the CLI's own sparkle while it works.

How it works

Each card drives the preview above.

Chat UI

Claude Code, drawn by Astral.

Claude runs headless with --output-format stream-json and Astral draws the conversation: streamed markdown, a folded "Thinking" block, tool calls you can expand to see the command and its output, permission prompts as cards with Allow and Deny. Enter sends, Shift+Enter adds a line, Esc interrupts.

Terminal UI

Every other CLI, untouched.

Codex, Gemini CLI, Grok, Copilot, OpenCode, Qwen Code, Kimi, Aider and local models open in a real ConPTY terminal with their own interface. Astral never patches a CLI. It launches the vendor's binary exactly as you would from PowerShell and watches its output for the working state.

Spinners

Each agent's own working indicator.

Claude Code's sparkle and random verb ("Combobulating…", "Clauding…"), Codex's braille spinner with elapsed time, Aider's scanner bar. The same indicator shows in the tab and in the sidebar row, so you can see what every workspace is doing from anywhere.

Workspaces

Worktrees, so agents don't collide.

Every repository gets a "local" workspace that is the folder itself. New workspace (Ctrl+N) makes an isolated git worktree on its own branch, so an agent can rewrite half the app while your checkout stays clean. Alt+Left and Alt+Right walk back through the ones you visited.

Queue

Messages queue while Claude is busy.

Send while a turn is running and the message waits above the input, delivered when the turn ends. Ctrl+Enter interrupts and sends now instead. Work done through Claude's Agent tool streams back under its step with a live line and a step count.

Handoff

Switch agents mid-project.

Open Codex in a workspace that already has a Claude conversation and Astral writes a brief of it (what was asked, files changed, recent commands, last replies) to .astral/handoff.md. The new agent's first message tells it to read that before anything else.

Git

Diff, PR and checks in the panel.

Diff shows git status with line counts and lets you leave review comments that go to the agent. Checks shows the open PR, its CI, and a merge button. Commit and push, pull latest and create PR live in the … menu, and every git step runs in a visible shell in the drawer.

Resume

Pick up any conversation.

Chat history is saved, so a relaunch shows everything. Ctrl+Shift+R opens a resume picker that reads the transcripts Claude Code and Codex already write, including conversations started outside Astral, from any folder on the machine.

Settings

Agents, scripts, shortcuts.

Settings lists every supported CLI with installed and latest versions and an install button that runs the vendor's own command in a visible terminal. Repositories get setup and run scripts (they become tabs). The full key list is under Shortcuts.

Run it from your phone

Astral can serve itself to your phone. Switch hosting on and the same conversations appear in one column on a handset: the same chat rendering, agent marks and working animations, the model, permission and effort chips, and a settings sheet behind the gear. Change a setting there and it applies on the PC too.

  1. Open Settings → General → Phone and press Start hosting.
  2. Astral serves a small site from the PC and shows an address like http://192.168.1.20:5175 along with a 4-digit code.
  3. Open that address on your phone and type the code. No account, and nothing to install.
Away from home. Turn on Internet access (port forwarding) in the same settings. Astral shows your public address, switches to an 8-character code, and lists the router steps for you. No outside service sits in the middle. If your ISP uses shared addressing, inbound connections are blocked and a private network like Tailscale is the way round it.
It keeps running. While hosting, closing the window hides Astral to the system tray rather than quitting, so the chats and the phone site stay up until you stop hosting or the PC shuts down.

Install it

Windows only for now (it uses ConPTY and PowerShell). You need Node 22 or newer, Git on the PATH, and at least one coding CLI.

# a CLI to host, for example Claude Code
npm install -g @anthropic-ai/claude-code
claude          # run once to log in

# the app
git clone https://github.com/maxwitanowski/Astral-Coder.git
cd Astral-Coder
npm install
npm start
  1. npm start builds the interface and opens the app. After that, Astral.vbs launches it without a console window (make a shortcut for the taskbar).
  2. Optional: the GitHub CLI for pull requests and checks. Astral can install it from the Checks tab, then run gh auth login.
  3. Every other supported CLI can be installed from Settings → Agents, which runs the vendor's install command in a visible terminal.

Where things live

  • astral.jsonProjects, workspaces, sessions and settings in %APPDATA%\Astral, with a .bak of the last good copy beside it.
  • chats\Chat history per Claude session, one JSON file each.
  • handoff.mdThe brief for the next agent, in <workspace>\.astral\, excluded from git automatically.
  • worktreesIsolated workspaces live in %USERPROFILE%\conductor\workspaces.

Under the hood

  • Terminalsnode-pty (ConPTY) in the Electron main process, xterm.js in the window. CLIs start through PowerShell with a UTF-8 console.
  • Claude chatclaude -p --input-format stream-json --output-format stream-json --permission-prompts host, with a known session id so the transcript path is known, and model, effort and add-dir flags only when you set them.
  • Live status~/.claude/sessions/*.json for Claude Code; output activity for everything else.
  • TranscriptsClaude's and Codex's own JSONL transcripts are read for history, the resume picker and the handoff brief. Nothing is ever written to them.
  • EnvironmentCLAUDE_* variables are stripped from child processes, so an Astral launched from inside a Claude Code session doesn't confuse the CLI it starts.

Minebro

A real player, not a mob

The bot is a real ServerPlayer on a fake network connection, the same trick the Carpet mod uses for fake players. Vanilla handles its hunger, health, chunk loading, saving, death and respawn. It shows up in the tab list and keeps its inventory between sessions.

It thinks in a loop

A brain thread builds an observation of what the bot can see, sends it to the model with a list of tools, then runs whatever the model picks on the server thread. It thinks when you chat, when a task finishes, and otherwise every 30 seconds.

It plays fair

Only blocks and mobs hit by its eye rays exist for it. Reach is 4.5 blocks, mining takes the real time for the tool it holds, and it needs line of sight to hit anything. It can see what you hold and wear, but not your inventory, health or hunger.

Body and brain are separate

Every tick a controller runs the current task and sets movement inputs like a client would. Pathfinding, digging with vanilla timing and GUI-less crafting all live in the body. The model never touches physics.

How to install

Four advancements. Tick them off as you go. Nothing to install for anyone else who joins your world.

1 · Install Fabric for 26.2

  • Get the Fabric installer from fabricmc.net. Pick Minecraft 26.2, loader 0.19.3 or newer, click Install.
  • Download Fabric API for 26.2 from Modrinth (fabric-api-0.157.0+26.2.jar or similar).

2 · Drop in the jar

Grab minebro-0.1.0.jar from the Releases page and put it next to Fabric API in your mods folder:

  • Windows: %APPDATA%\.minecraft\mods
  • macOS: ~/Library/Application Support/minecraft/mods
  • Linux: ~/.minecraft/mods

Launch the fabric-loader-0.19.3-26.2 profile once to create config/minebro.json. Dedicated server: same two jars in the server's mods folder.

3 · Get an API key

Anthropic

Default. Key from console.anthropic.com, model claude-sonnet-5.

OpenRouter

Key from openrouter.ai. Any model with tool calling.

OpenAI-compatible

Point baseUrl at OpenAI, LM Studio or Ollama for local models.

4 · Enter the key, spawn it

Open a world and type in chat:

/ai set key sk-ant-...
OpenRouter: /ai set provider openrouter, then /ai set key sk-or-...

Saved to config/minebro.json, so it's a one-time thing. Environment variables ANTHROPIC_API_KEY / OPENROUTER_API_KEY work too. Then:

/ai spawn

It appears next to you, says hello, and starts looking around. Just talk in normal chat.

Commands

Click a row to try it in the chat above.

CommandWhat it does
/ai spawnSpawns Minebro next to you. Inventory and position carry over between sessions.
/ai goal <text>A standing job it sees every turn. /ai goal clear removes it.
/ai chat <text>Send it a message without broadcasting it.
/ai statusCurrent task, queue, model in use, last error.
/ai observePrints exactly what the model sees this turn.
/ai stop · pause · resumeCancel what it's doing, or stop and restart model calls. No API cost while paused.
/ai set model …Swap models any time: claude-opus-5, google/gemini-3.8-flash via OpenRouter, or a local LM Studio model.
/ai do <tool> <json>Run one ability directly, no model involved.
/ai despawnRemoves it, like logging out. Everything is saved.
Cost: each model call is a few thousand mostly-cached tokens. With Sonnet 5 that's well under $1 USD per hour of play.

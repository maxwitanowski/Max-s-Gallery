Notepad

Apple Notes simplicity, Obsidian-style links and tags, on a page that feels like paper. Plus two party tricks: ink mode, where you write words with your cursor and they turn into text, and an eavesdropper that listens to whatever is playing, transcribes it locally, and writes study notes into the open note while you watch.

How it works

Each card opens that part of the preview.

#notes

Plain files, no lock-in.

The vault is a folder of Markdown files (Documents\Notepad by default), so it opens in Obsidian too. Folders are folders. Deleted notes go to a .trash folder inside the vault, so nothing is ever really lost. Notes save as you type.

#links

[[Links]], backlinks and tags.

Type two square brackets and pick a note. Ctrl+click a link to follow it; a missing note is created on the spot. Write #tags anywhere and they appear in the sidebar as filters. The link icon shows what this note points to and what points back.

#ink

Write with your cursor.

Press the pen (or Ctrl+D), hold the mouse and write a word on the page. Pause for a second and the strokes go to Google's free handwriting service, then the text lands on the line you drew over. A cheap vision model is the fallback. Off in this preview because it leans on those services; it works in the app.

Install the app to try it.
#eavesdrop

Notes on whatever is playing.

Pick the output device your lecture or call plays through, press Start listening, and RtAudio opens that device in loopback. Whisper transcribes it on your PC in a worker thread, and every minute an AI rewrites a set of study notes inside the note. Stop, and the timestamped transcript is saved as a linked note. Off in this preview because it needs Whisper and a notes model; it works in the app.

Install the app to try it.
#reading

Reading view and quick open.

Ctrl+E flips the page to rendered Markdown with clickable task boxes. Ctrl+P searches every note by name. Ctrl+N makes a new one, Ctrl+, opens settings, Ctrl+\ hides the sidebar.

#local

Free by default, AI only where you add a key.

Audio never leaves the computer; only the transcript text goes to the notes model. Without an OpenRouter key you still get ink-to-text and transcripts. The key lives in %APPDATA%\Notepad\settings.json.

Install it

Windows 10 or 11 (the eavesdropper uses WASAPI loopback; the rest runs anywhere Electron does), Node.js 22 or newer, and optionally an OpenRouter key.

git clone https://github.com/maxwitanowski/Notepad.git
cd Notepad
npm install

npm run dev      # Vite dev server + Electron with hot reload
npm start        # build the renderer and launch the app
npm run dist     # NSIS installer lands in release/
  1. Launch it. A vault is created at Documents\Notepad with a Welcome note.
  2. Open Settings (gear icon or Ctrl+,). Point the vault at another folder if you like, such as an existing Obsidian vault.
  3. Optionally paste an OpenRouter key. It enables AI notes, summaries and the vision fallback for handwriting.
  4. For the eavesdropper, pick the output device your audio actually plays through under Listen to. With a mixer like SteelSeries Sonar, browsers usually sit on "Media".

Under the hood

  • Notes on diskelectron/vault.cjs · folders are folders, notes are .md, deletes go to .trash
  • EditorCodeMirror 6 with Markdown, [[ autocomplete and Ctrl+click links; markdown-it for reading view
  • InkStroke data to Google's handwriting endpoint, vision-model fallback, text inserted at the drawn line
  • Audioaudify (RtAudio 6, WASAPI) opens the chosen output device in loopback at 16 kHz; chunks cut on pauses
  • Speech to texttransformers.js + onnxruntime in a worker thread, Xenova/whisper-base.en by default, downloaded once
  • AI notesOpenRouter, z-ai/glm-5.3, rewrites the notes between eavesdropper markers in the note
